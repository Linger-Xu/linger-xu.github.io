Research Projects

Multimodal Fusion-based Emotion Recognition Dataset and Model Construction
[Paper(available after 2025.5.22)]
We have designed a multimodal emotion recognition model to address the shortcomings of traditional single modal emotion recognition, such as low robustness and inability to explore correlations between different modalities. In terms of audio, we extracted three complementary features: semantic embedding features provided by Wav2Vec2, MFCC features, and comprehensive audio features, and modeled them with BiLSTM and time series. In terms of vision, we designed a ResNet50 BiLSTM structure to extract spatiotemporal emotion features from videos through residual learning and sequence modeling. In addition, a feature layer fusion method based on multi head attention mechanism is proposed. The accuracy on both MELD and IEMOCAP datasets is better than the baseline method, and further ablation experiments verify the significant improvement in performance under data imbalance.
Hex Game Robot Based on Monte Carlo Tree Search (MCTS)
[Repository]
This project uses Monte Carlo search algorithm as the core search mechanism, combined with maximum flow evaluation function to enhance the evaluation ability of the situation. At the same time, it adopts a win loss judgment mechanism based on parallel search set optimization and integrates a series of expert strategies ("bridge" operations) to improve the adaptability and strategic nature of the algorithm. One of the initial bots of the project ranked 26th on the overall Hex Chess leaderboard on the botzone platform (as of April 1, 2025), and the project won the first prize in the 2024 China University Student Computer Game Competition (Hex Group).
Qile Longlong - CPU Based on LoongArch32 Reduced Instruction Set
[Repository]
Designed a processor implementing the LoongArch32 reduced instruction set with a 6-stage pipeline, supporting 72 integer and privileged instructions (excluding floating-point). Implemented exception and interrupt mechanisms, AXI interface, and TLB MMU support. Achieved a maximum frequency of 45MHz in testing. Won the National Third Prize in the 8th National College Student Computer System Ability Competition (Loongson Cup).
Movie History and Audience Preference Analysis - Big Data Project with Hadoop & Spark
[Repository]
Developed a comprehensive big data analysis system to study movie trends and audience preferences using Hadoop HDFS for distributed storage and Spark for data processing. Implemented data cleaning, statistical analysis, and visualization with Python libraries (pandas, matplotlib, seaborn). Key achievements include:
  • Analyzed historical trends of movie ratings across years, regions, genres, and directors
  • Developed a composite scoring system to evaluate film quality by country
  • Created a "cold movie index" algorithm to identify high-quality underrated films
  • Discovered seasonal and time-of-day patterns in audience rating behavior
  • Built a distributed processing cluster with Hadoop 2.7.2 and Spark 2.1.0
The project provides actionable insights for film production, marketing strategies, and academic research in the movie industry.
SNL Language Compiler
[Repository]
A complete compiler for SNL (Simplified Nested Language) implementing lexical analysis (DFA), syntax analysis (recursive descent parsing), semantic analysis with hierarchical symbol tables, and MIPS code generation. Developed in C++ with STL, featuring nested procedure support and stack-based memory management, validated using MARS simulator.
CUMCM2023 - Solution for the 2023 National College Student Mathematical Modeling Competition
[Repository]
This project provides a comprehensive solution for optimizing the pricing and restocking strategies of perishable goods in large supermarkets. It addresses the challenge of short shelf-life and seasonal demand variations by employing advanced analytical techniques such as time series analysis, grey prediction models, and linear programming. The solution includes detailed analysis of sales data, prediction of future sales trends, and optimization of restocking quantities and pricing to maximize profits while minimizing waste. The project was awarded the First Prize in the Jilin Province for the 2023 National College Student Mathematical Modeling Competition.
